Kết nối Google Apps Script

Dán URL Web App dạng https://script.google.com/macros/s/AKfycbwA4_PMAo0LvbL8iUsZXQTDS_X-VfBuh5Pp5mGFApSry6B5As4GLdf1opzwgCf6QWNt/exec. URL được lưu trong trình duyệt này.

Cách triển khai

1. Mở Google Sheet → Tiện ích mở rộng → Apps Script → dán Code.gs.

2. Deploy → New deployment → Web app → Execute as Me → Who has access: Anyone.

3. Copy URL /exec và dán bên trái.

4. Up index.html lên GitHub, import repo vào Vercel.
