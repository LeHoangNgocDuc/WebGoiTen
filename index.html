Kết nối Google Apps Script

V12 dùng proxy Vercel /api/sheet. Vòng quay và điểm lần gọi dùng chung dữ liệu Google Sheet.

🔴 CHỖ DÁN LINK TRONG SOURCE
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbwJGI14qSGHWHJWVi75tMzKcir_uU8OoxajKt2VDbPLtz4krl-uJWbgSjABX81r6yOE/exec'; // V6: trình duyệt chỉ gọi API cùng domain Vercel. File api/sheet.js sẽ gọi Apps Script. const API_PROXY_URL = '/api/sheet';
Chưa kiểm tra.

      

      

        
Triển khai đúng

        
1. Mở đúng Google Sheet → Extensions → Apps Script → dán Code.gs mới.

        
2. Trên thanh chọn hàm setup → Run → cấp quyền. Chỉ làm 1 lần.

        
3. Deploy → Manage deployments → Edit → New version → Execute as Me → Who has access: Anyone.

        
4. GitHub/Vercel phải có thêm file api/sheet.js. Đây là proxy giúp tránh lỗi gọi trực tiếp Google từ trình duyệt.

        
5. Upload index.html và thư mục api/sheet.js lên GitHub/Vercel → chờ Ready → Ctrl+F5 → Kiểm tra và nạp dữ liệu.
