LỚP HỌC TƯƠNG TÁC 3D V9
=======================

BẢN NÂNG CẤP TRÒ CHƠI 2 ĐỘI
- Cùng 1 câu hỏi cho cả Đội Xanh và Đội Đỏ.
- Giao diện mới chia 3 cột: Câu hỏi Đội A | Sân 3D | Câu hỏi Đội B.
- Hình ảnh của câu hỏi hiển thị ở trên cùng.
- Bên dưới là nội dung câu hỏi.
- Bên dưới nữa là đáp án theo lưới 2 cột đều nhau.
- Nếu đội đang mở lượt trả lời sai, quyền trả lời chuyển sang đội còn lại.
- Nếu đội trả lời đúng sẽ được cộng 1 điểm và hoạt ảnh 3D chuyển động.
- Nếu cả hai đội cùng sai, hệ thống hiện đáp án đúng và chờ câu tiếp theo.
- Đồ họa 3D được giữ ở giữa, chuyển động mượt hơn để phù hợp trình chiếu lớp học.

FILE DÙNG NGAY
- index_v9.html : file hoàn chỉnh để thay trực tiếp cho index.html trên GitHub / Vercel.

CÁCH CẬP NHẬT
1. Tải file index_v9.html.
2. Đổi tên thành index.html.
3. Upload đè lên file index.html cũ trên GitHub.
4. Nếu đang dùng Vercel, chờ Vercel deploy xong.
5. Nhấn Ctrl+F5 để tải lại trình duyệt.

LƯU Ý
- Không cần sửa Code.gs cho phần giao diện trò chơi này.
- Nếu câu hỏi có URL ảnh nằm trong nội dung Question, ảnh sẽ tự hiện ở phía trên.
- Nếu JSON có trường Image hoặc image thì ảnh cũng sẽ được ưu tiên hiển thị.

NẾU MUỐN TÁCH FILE RIÊNG
- Có thể dùng bản index_v9.html trước.
- Nếu cần, có thể tách phần game ra thành game.css / game.js ở lần tiếp theo.
