Kết nối Google Apps Script

V4.1 lấy URL trực tiếp từ index.html. Không còn đọc URL từ localStorage nên tránh dùng nhầm link cũ.

🔴 CHỖ DÁN LINK TRONG SOURCE
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/.../exec';
Chưa kiểm tra.

      

      

        
Triển khai đúng

        
1. Mở đúng Google Sheet → Extensions → Apps Script → dán Code.gs mới.

        
2. Trên thanh chọn hàm setup → Run → cấp quyền. Chỉ làm 1 lần.

        
3. Deploy → Manage deployments → Edit → New version → Execute as Me → Who has access: Anyone.

        
4. Mở index.html → tìm chữ DÁN LINK GOOGLE APPS SCRIPT WEB APP → thay URL trong biến APPS_SCRIPT_URL.

        
5. Upload index.html lên GitHub/Vercel → chờ Ready → nhấn Ctrl + F5 → bấm Kiểm tra và nạp dữ liệu.
